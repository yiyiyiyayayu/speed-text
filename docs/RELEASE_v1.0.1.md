NodeScope 1.0.1 · 订阅导入兼容修复

- 新增 HTTPS 远程 `proxy-providers` 加载，支持相对地址、内嵌节点源和节点去重，无需在线订阅转换站。
- 使用标准 Clash 客户端标识，提高订阅服务器的格式识别兼容性。
- 修复空响应、网页和没有节点的接口信息被误提示为远程节点源的问题。
- 节点源加载失败时保留原订阅；增加循环、嵌套、总大小和 HTTPS 降级检查。
- 改善超时、证书、域名解析和服务器拒绝访问的提示，错误中不包含订阅凭据。

核心回归测试使用虚构订阅和本地 HTTPS 服务，不含真实用户链接或节点。

iOS 16+。下载 `NodeScope-unsigned.ipa` 后导入全能签，使用自己的有效证书与描述文件签名安装。
