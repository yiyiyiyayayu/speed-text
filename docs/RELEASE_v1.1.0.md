# NodeScope 1.1.0

- 新增自动记忆的地区排除（例如香港）、单节点排除和服务器 IP / 域名精确排除；更新订阅后地区规则继续有效。排除节点跳过测速、推荐和续测，不删除节点或记录。
- 新增「网络」页，分别命名移动蜂窝、移动 Wi-Fi、电信 Wi-Fi 等档案，各自保存历史与推荐。自动识别网络类型，同类 Wi-Fi 需手动选择档案，不依赖读取 Wi-Fi 名称的签名权限。
- 新增可关闭的短时后台续测。系统时间到或检测到网络变化时保存队列，回前台后手动继续；用户主动停止则放弃队列。无法保证持续后台运行或固定时长。
- 缩小概览与节点卡片，关键延迟、抖动、失败率、评分紧凑显示；完整样本、P95 与跨网络历史在详情查看。
- 旧版订阅、下载设置和历史兼容保留。旧版未区分网络的记录独立查看，不混入新档案评分。

下载 `NodeScope-unsigned.ipa`，用全能签 / ESign 与有效证书、描述文件重新签名后覆盖安装。沿用原签名身份与 Bundle ID 才能保留钥匙串与本地数据。最低 iOS 16，后台时长由系统决定；尚未在 iOS 27 真机验证。

校验文件见 `SHA256SUMS.txt`。源码与构建脚本随标签公开，不包含真实订阅与节点凭据。
