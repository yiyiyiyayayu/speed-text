# NodeScope 1.2.0

- 新增「暂停测速」与「继续」，保留已完成记录、批次和剩余进度；重启 App 后仍可恢复。未完成节点重新采样，恢复沿用原网络档案和设置。「停止并放弃」才会清空队列。
- 下载测速分开计算建连首包耗时、短预热和有效正文均速；采样期间的停顿仍计时。旧版含建连均速保留并明确标记。
- 修复默认下载 URL 总是返回 8 MiB 的问题，现按所选上限请求数据。自定义 URL 保持原样，默认端点防缓存。
- 可选单连接或 4 连接，共用每节点读取上限，预热也计入上限。不同节点仍串行测试。原有开关与流量设置不自动改变。
- 同时显示 Mbps 与 MB/s。短样本、连接未全部参与或部分失败标为估计；极短样本不报速度。详情展示有效时长、读取量、预热与连接数。下载排序优先新口径结果，稳定性评分不变。
- 新增用户主动选择的较长采样预设（64 MiB / 8 秒 / 4 连接）。高速节点需要足够数据，测试源限速与网络状态仍会影响数值；不保证与其他测速软件一致。

下载 `NodeScope-unsigned.ipa`，使用全能签 / ESign 与原签名身份、Bundle ID 覆盖安装。最低 iOS 16；后台续测由系统决定，尚未在 iOS 27 真机验证。实际流量包含缓冲与协议开销，读取上限不是运营商账单的硬限额。

校验值见 `SHA256SUMS.txt`，源码与构建脚本随标签公开。
